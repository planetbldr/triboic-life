# Code

Scripts behind every quantitative result in the reports, organized by gate.
Drag your `.py` files into the matching subfolder:

- `gate0_redox/`         — t1_ferrocene.py, t2_quinone.py, t3_semiquinone.py, t4_buffering.py
- `gate1_whip/`          — g1a_repin_tribopositive.py, g1b_flutter_envelope.py, g1b_impedance.py
- `gate3_coating_ledger/`— g3a_step0_duty_cycle.py, g3a_diagnostic.py, g3b_continuity.py, g3b_ledger_v2.py
- `gate4_atmosphere/`    — g4a_ through g4f_ exchange scripts

If you also include an `environment.yml`, others can recreate the setup and re-run the numerical work.
